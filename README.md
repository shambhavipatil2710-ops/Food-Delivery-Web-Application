 🍔 Food Delivery Web Application

A full-stack Food Delivery Web Application developed using **Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript**. The application follows the **MVC (Model-View-Controller) architecture** and **DAO (Data Access Object) design pattern** to provide a structured, maintainable, and efficient online food ordering system.

 📌 Project Overview

The Food Delivery Web Application is designed to simplify the online food ordering process. Users can browse restaurants, explore food menus, add food items to their shopping cart, and place orders through an interactive web interface.

The project demonstrates Java Full Stack Development concepts, including database connectivity, session management, CRUD operations, and frontend-backend integration.

🚀 Key Features

- User Registration & Login:User authentication and session management.
- Restaurant Management: Display and manage restaurant information.
- Menu Management: Browse available food items and their details.
- Shopping Cart:Add, update, and remove food items.
- Checkout System: Review selected items and proceed with orders.
- Order Processing: Handle customer food orders.
- Database Integration: Perform CRUD operations using JDBC and MySQL.
- Responsive Interface: User-friendly pages built with JSP, HTML, CSS, and JavaScript.

 🏗️ Project Architecture

The application follows MVC architecture:

- Model: Represents application entities such as users, restaurants, menus, and orders.
- View: JSP pages provide the user interface.
- Controller: Java Servlets process requests and manage application workflows.
- DAO Layer: Handles database operations through JDBC.

 📂 Project Structure

The Java backend includes the following components:

- `DAO` – Data access interfaces.
- `DAOImpl` – Implementation of database operations.
- `model` – Application data models.
- `utility` – Utility and helper classes.
- `LoginServlet` – Handles user login.
- `RegisterServlet` – Handles user registration.
- `RestaurantServlet` – Handles restaurant-related requests.
- `MenuServlet` – Handles menu-related requests.
- `SessionServlet` – Handles session-related functionality.

The application also uses JSP pages, CSS, and JavaScript for the frontend.

 ⚙️ How to Run the Project

 Prerequisites

- Java JDK
- Eclipse IDE
- Apache Tomcat
- MySQL Server
- MySQL JDBC Driver

Installation Steps

1. Clone the repository:

   `git clone https://github.com/shambhavipatil2710-ops/Food-Delivery-Web-Application.git`

2. Open Eclipse IDE and import the project.

3. Configure Apache Tomcat in Eclipse.

4. Create the required MySQL database and import the project database schema, if provided.

5. Configure database connection settings with your local MySQL credentials.

6. Ensure the required dependencies are configured.

7. Run the application using "Run As → Run on Server".

8. Open the application in your browser using the context path configured in Tomcat.
